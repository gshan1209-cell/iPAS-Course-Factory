# iPAS-Course-Factory

半自動教材工廠（Course Factory），用於把官方來源穩定轉換為可追蹤、可驗證、可重製的多載體教材資產。

## Current Stage

- DEV1｜Specification
- Architecture design in progress
- Implementation has not started

## Core Principle

GitHub is the control plane and canonical source of truth for manifests, templates, workflow state, governance, and QA rules. Google Drive is the asset plane for official sources and generated course artifacts.

## Initial Scope

Target course: iPAS AI 應用規劃師（中級）

Automation target: 半自動教材工廠（B）

Human gates remain for NotebookLM slide review, voice review, CapCut assembly, and final publication.
