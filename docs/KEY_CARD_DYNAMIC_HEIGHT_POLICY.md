# iPAS 重點卡｜動態高度規範

版本：KCT-v3.2
生效日：2026-08-20

## 核心原則

> 寧可拉高卡片，不可縮小字體。

重點卡固定寬度為 1024 px。標準版高度為 1536 px；若內容在維持標準樣本字級與閱讀性後仍無法容納，必須改用延伸版，動態增加高度，不得以縮小字體、過度壓縮行距或刪除必要內容的方式硬塞。

## 雙模板規格

### STANDARD｜標準版
- 尺寸：1024 × 1536 px
- 預設使用
- 必須維持 KCS-v1.0 標準樣本的字級、視覺層級與內容密度基準

### EXTENDED｜延伸版
- 寬度：固定 1024 px
- 高度：動態
- 起始條件：高度 > 1536 px
- 建議高度：1700 / 1850 / 2048 px
- 若仍不足，可繼續向下延伸
- 區塊順序、字級、卡片識別、星級、標籤與出處規則皆與標準版一致

## 內容溢位處理順序

1. 精簡文案，但不得改變考點原意。
2. 移除重複或非必要的解釋句。
3. 在可讀範圍內縮減非語意留白。
4. 切換 EXTENDED 延伸版。
5. 增加高度直到可讀。
6. 若內容其實包含兩個以上獨立考點，拆成多張卡，不得用超長卡片強行合併。

## 禁止事項

- 禁止為了塞版而縮小正文、標題或出處字體。
- 禁止壓縮行距到影響閱讀。
- 禁止刪除生活舉例來節省空間。
- 禁止刪除出處來節省空間。
- 禁止把多個獨立考點塞在同一張卡。

## QA Gate

製卡 QA 必須確認：
- 寬度為 1024 px。
- STANDARD 高度為 1536 px。
- EXTENDED 高度可動態增加。
- 字體不得低於標準樣本 KCS-v1.0 的比例基準。
- 若發生內容溢位，優先加高而不是縮字。
- 一張卡仍只聚焦一個考點。
