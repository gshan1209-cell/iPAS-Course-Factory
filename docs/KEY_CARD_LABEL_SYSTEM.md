# iPAS 重點卡｜Card Label System v1.0

Status: **APPROVED / ACTIVE**  
Effective: 2026-08-20

## Purpose

把「考試重要度」「卡片記憶模式」「考試特性」拆成三個互不混淆的視覺層：

1. **星級／出題比例**：只表示考試優先度。
2. **類別專屬標籤**：只表示這張卡應用哪種方式學習與記憶。
3. **輔助標籤**：補充必考、易錯、重複出題、新興考點等考試特性。

## 類別專屬標籤

| 資料層卡片類型 | 卡面標籤 | Icon | 系統短碼 | 色彩語意 |
|---|---|---|---|---|
| 概念卡 | 核心概念 | 💡 | `CONCEPT` | 藍 |
| 比較卡 | 差異比較 | ⚖️ | `COMPARE` | 紫 |
| 流程卡 | 流程必背 | 🔄 | `FLOW` | 青綠 |
| 陷阱卡 | 考題陷阱 | ⚠️ | `TRAP` | 紅／橘紅 |
| 公式卡 | 公式計算 | 🧮 | `FORMULA` | 深藍 |
| 情境卡 | 情境判斷 | 🎯 | `CASE` | 橘 |
| 真題卡 | 歷屆真題 | 📝 | `EXAM` | 金 |
| 總整理卡 | 考前速讀 | 🧠 | `REVIEW` | 深紫／墨色 |

## 輔助標籤

| 標籤 | 短碼 | 用途 |
|---|---|---|
| 🔥 必考 | `MUST` | 核心能力或高考試優先度 |
| ❗ 易錯 | `ERROR` | 高混淆、高誤判、高干擾選項風險 |
| 🔁 重複出題 | `REPEAT` | 多次正式公告試題重複命中 |
| 🆕 新興考點 | `NEW` | 新試題首次或近期新增的重要考點 |

輔助標籤為可疊加屬性，預設每張卡最多顯示 3 個，避免卡面資訊過載。

## 卡面資訊順序

1. 星級＋出題比例，例如 `⭐⭐⭐⭐⭐｜32.7%`
2. 類別專屬標籤，例如 `⚠️ 考題陷阱 · TRAP`
3. 輔助考試標籤，例如 `🔥必考｜❗易錯｜🔁重複出題`
4. 主題標題
5. 核心內容
6. 一句記憶／考場判斷

## 資料與視覺分層

後台 Master Index 仍保存正式資料型別，例如 `概念卡`；卡面顯示 `💡 核心概念`；系統使用穩定短碼 `CONCEPT`。

不得用類別色彩暗示星級高低。星級可因最新試題重算而改變，但卡片類別不必跟著改；反之，教學設計調整卡片類別時也不得改寫 computed star。

## Governance

Machine-readable policy: `sources/registry/key-card-label-policy.yaml`  
Star policy: `sources/registry/key-card-weight-policy.yaml`

所有初級與中級重點卡、Master Index、製卡模板與 QA 應引用本規範。任何新增類別或短碼都必須先更新 policy，再更新模板與 Master Index，避免資料漂移。
